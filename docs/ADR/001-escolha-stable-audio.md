# ADR 001 - Escolha Stable Audio 2.5 como primária

Data: 2026-09-29
Decisão: Usar Stable Audio 2.5 como geradora principal no MVP porque tem API pública estável e controle de stems. Suno v5.5 tem qualidade vocal superior mas sem API pública oficial (apenas beta parceiros) em 2026.
Consequência: MVP gera instrumentais excelentes. Voz via ElevenLabs.
