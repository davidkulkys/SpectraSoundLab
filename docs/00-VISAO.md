# SpectraSoundLab - Visão

**O que é:** Gerador de música que transforma briefing humano (texto, imagem, vídeo, humming) em música completa seguindo parâmetros pré-definidos.

**Fluxo:** Capture (UI) -> Interpret (Gemini 1.5 Flash multimodal) -> Generate (Stable Audio 2.5 / Suno v5.5) -> Player + Biblioteca

**Público:** Criadores, designers, produtoras que precisam de trilha rápida sem depender de biblioteca genérica.

**Diferencial:** Não é texto->musica. É moodboard->musica com BPM, Tom, Energia travados.
