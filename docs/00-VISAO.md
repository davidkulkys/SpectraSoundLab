# SpectraSoundLab - Visão v3 - Fábrica

**O que é:** Fábrica que gera em lote uma BASE de músicas por estilo musical. NÃO roda no cliente comercial.

Fluxo:
SpectraSoundLab (fábrica, roda só no dono) -> Gera em lote via Motor A grátis (ACE-Step) -> Salva em /music-base/{estilo}/ -> Outro App do Cliente Comercial baixa as músicas da base e toca na loja.

Problema que resolve: Cliente não paga ECAD porque músicas são 100% IA com certificado royalty-free. Dono da fábrica tem custo zero com geração em lote via modelos chineses gratuitos.

Estilos iniciais: lo-fi, mpb-moderna, bossa, phonk, cinematic, eletronica, trap, indie-pop
Meta: 200 faixas por estilo = 1600 faixas base inicial.
