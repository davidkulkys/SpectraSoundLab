# SpectraSoundLab - Stack Travada

**Imutável. Não trocar sem ADR.**

- Framework: Next.js 14.2.5 App Router
- Linguagem: TypeScript 5.4
- Estilo: Tailwind CSS 3.4 + shadcn/ui
- Backend: Firebase - Hosting, Auth (email), Firestore, Storage, Functions v2 (Node 20 LTS)
- IA Interprete: Gemini 1.5 Flash (multimodal: texto+imagem+video+audio)
- IA Geradora: Stable Audio 2.5 API (primária) + ElevenLabs Music (voz) + Suno v5.5 (parceria futura)
- Package Manager: npm
- Node: 20 LTS

**Proibido usar:** Prisma, Supabase, outra lib de UI, outro banco.
